# Pure CSS Sidebar Menu

A simple sidebar menu project built using HTML and CSS to practice front-end web development skills.

## Features

- Open and close sidebar menu
- Navigation menu with icons
- Hover effects on menu items
- Social media icons
- Simple and clean design

## Technologies Used

- HTML5
- CSS3
- Font Awesome for icons
- Google Fonts (Poppins)

## Project Files

- `sidebar_purecss.html` – Contains the HTML structure.
- `style1.css` – Contains the styling and animations.

## How to Run

1. Download or clone this repository.
2. Keep both files in the same folder.
3. Open `sidebar_purecss.html` in your web browser.

## What I Learned

- Structuring a webpage using HTML
- Styling elements using CSS
- Using CSS selectors and hover effects
- Creating a sidebar toggle using a checkbox and CSS
- Adding icons and custom fonts to a webpage
